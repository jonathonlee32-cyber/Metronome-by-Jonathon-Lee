# Metronome

一个简单的 Android 节拍器应用。

## Features

* BPM 调节
* 节拍播放
* 简洁界面
* Android 16 支持
* 无广告，不盈利
* 每日时间记录：自动记录每次练习的开始 / 结束时刻与时长，按日期分组统计今日、本周、累计练习时间

* Kotlin
* Android SDK
* Jetpack Compose
